# Creative & Media Plugin

Connect `aria-creative-media` in `mcp.json`, then call:
- `creative_figma_summary` / `creative_figma_comments` (read-only Figma inspection)
- `creative_canva_autofill` / `creative_canva_upload_asset` (Canva Connect)
- `creative_image_generate` / `creative_image_edit` (OpenAI Images API)
- `creative_video_submit` / `creative_video_poll` (Kling / Runway video generation)
