# Aria Creative & Media Plugin

Standalone MCP plugin migrated from `aria-code` core:
- **Figma**: `figma_client.py`
- **Canva**: `canva_client.py`
- **OpenAI Images**: `openai_image_client.py`
- **Video**: `kling_video_client.py`, `runway_video_client.py`

## Run tests

```bash
PYTHONPATH=plugins/creative-media/python pytest plugins/creative-media/tests
```
