USE IN ARIA CODE

The same workflow.
Inside your agent.

Install the Commerce skill, connect its Go tools, and let Aria prepare a draft. Review and approve the exact invoice in the browser.

Read the connection guide ↗

Skill installation and MCP setup are separate steps. A configured Aria model is required to use the agent.

  1. 01

    Install and verify the skill

    Enter each command separately in your Aria Code session.

    /skills add artheras/aria-plugins
    /skills doctor
  2. 02

    Connect the Go MCP tools

    Build and start the Commerce service. Register the MCP bridge using its absolute binary path and the agent merchant token; keep the browser login token separate.

    View configuration steps ↗
  3. 03

    Ask Aria for a draft

    $commerce:commerce Draft an order for 2 tees and 1 mug.

    Open the returned order in the browser. You control approval, checkout, and payment.
